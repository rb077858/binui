# לוח תחזוקה לפנימייה — הוראות הקמה

אתר סטטי לגמרי (HTML/CSS/JS ללא build) שמתחבר ל-Firebase. דיירים שולחים בקשת תיקון
לפי מספר חדר בלי להתחבר. גלגול הגלגלים למספר **67** ולחיצה ארוכה (כחצי שנייה) על
כפתור "שלח" פותחת מסך כניסת מנהל — רק חשבון Google עם המייל `rb077858@gmail.com`
מקבל גישה ליומן הבקשות.

## 1. יצירת פרויקט Firebase

1. גשו ל-[console.firebase.google.com](https://console.firebase.google.com) ← **Add project**.
2. אחרי יצירת הפרויקט: **Build → Firestore Database → Create database** (מצב Production, בחרו אזור קרוב, למשל `eur3`).
3. **Build → Authentication → Sign-in method** ← הפעילו **Google**, הזינו אימייל תמיכה ושמרו.
4. **Project settings (גלגל השיניים) → General** ← גללו ל-"Your apps" ← לחצו על סמל ה-Web `</>` ← תנו שם לאפליקציה ← העתיקו את אובייקט ה-`firebaseConfig` שמופיע.

## 2. חיבור הקוד לפרויקט

1. פתחו את `firebase-init.js` והדביקו את הערכים מ-`firebaseConfig` שהעתקתם (apiKey, authDomain, projectId וכו').
2. אם תרצו לשנות את חשבון המנהל, עדכנו את `ADMIN_EMAIL` באותו קובץ **וגם** את הכתובת בתוך `firestore.rules`.

## 3. פרסום כללי האבטחה (Firestore Rules)

ב-Firebase Console: **Build → Firestore Database → Rules** — הדביקו את תוכן הקובץ
`firestore.rules` מהתיקייה הזו ולחצו **Publish**.
הכללים מאפשרים לכל אחד ליצור בקשה חדשה, אך רק לחשבון המנהל לקרוא, לעדכן או למחוק.

## 4. הוספת הדומיין לרשימת המורשים

**Authentication → Settings → Authorized domains** — הוסיפו את הדומיין שבו יתארח
האתר (לדוגמה `<שם-המשתמש>.github.io`, או דומיין מותאם אישית אם יש לכם).
בלי זה, ה-Google Sign-In ייכשל.

## 5. העלאה ל-GitHub Pages

1. העלו את כל הקבצים בתיקייה הזו (`index.html`, `style.css`, `app.js`, `firebase-init.js`) לריפו ב-GitHub.
2. ב-Settings של הריפו → **Pages** → Source: **Deploy from a branch** → בחרו את ה-branch (למשל `main`) ותיקיית השורש (`/`).
3. אחרי דקה-שתיים האתר יהיה זמין בכתובת `https://<שם-המשתמש>.github.io/<שם-הריפו>/`.

## שימוש

- **דיירים**: גוללים את שני הגלגלים למספר החדר ולוחצים על הכפתור העגול — הבקשה נשלחת מיד, בלי צורך בהתחברות.
- **מנהל**: גוללים את הגלגלים ל-**67**, לוחצים לחיצה ארוכה (כ-0.6 שניות) על הכפתור, ואז לוחצים "התחבר עם Google" ומתחברים עם `rb077858@gmail.com`. חשבון אחר יידחה אוטומטית.
- ביומן הקריאות אפשר לסנן לפי סטטוס, לסמן קריאה כטופלה/לא טופלה, למחוק קריאה (לחיצה שנייה מאשרת), למחוק בבת אחת את כל הטופלות, לייצא הכול לקובץ CSV, ולשלוח את כל הקריאות / רק הממתינות כהודעת וואטסאפ.
